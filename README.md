# Hyto

Control de gastos y pagos por hitos para equipos. El presupuesto queda comprometido en un escrow de Trustless Work sobre Stellar, cada tarea se comprueba con evidencia y el pago se libera en USDC.

Organización: [Hyto-App](https://github.com/Hyto-App)

Contexto para quien construya:

- [PLAN.md](PLAN.md) — orden de trabajo de cada persona. Cada entrega va en una rama `nombre/tarea` y entra por pull request. Nadie sube directo a `main`.
- [STACK.md](STACK.md) — stack cerrado y reglas del dinero.
- [ROLES.md](ROLES.md) — qué hace cada persona. La IA de cada integrante actúa solo dentro de su rol.
- [Hyto-informe.md](Hyto-informe.md) — informe general: premisa, stack, roles, demo y calendario.

La app se despliega en Vercel. La base es Neon y las fotos están en Vercel Blob. La única computadora que tiene que quedar encendida es la de Abdiel, con Laya.
